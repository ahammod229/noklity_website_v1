NOKLITY Store - Customer Setup Guide

Version: White-label single-tenant deployment

Prepared for customer handover

What this guide does:

Step-by-step instructions to launch your own branded store instance with your own Supabase project, domain, payment setup, and admin control panel.

1) Prerequisites

  • Node.js 18+ installed
  • A Supabase account and a new project
  • Your domain/subdomain ready (optional for local setup)
  • Admin email(s) and super admin email(s)

2) Project Installation

  1. Open terminal in project folder.
  2. Run setup:
npm run setup:single-tenant
  1. This will install dependencies and create .env.local if missing.

3) Environment Configuration

Edit .env.local and fill at least:

VITE_SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_ANON_KEY
VITE_ADMIN_EMAILS=admin@yourdomain.com
VITE_SUPER_ADMIN_EMAILS=owner@yourdomain.com

VITE_TENANT_BRAND_NAME=YOUR BRAND
VITE_TENANT_DOMAIN=shop.yourdomain.com
VITE_TENANT_ALLOWED_HOSTS=localhost,127.0.0.1,shop.yourdomain.com
VITE_TENANT_PLAN_NAME=Enterprise
VITE_TENANT_LICENSE_STATUS=active
VITE_TENANT_LICENSE_KEY=NXL-ENTERPRISE-XXXXXXXX-XXXX
Security Rule: Never share or commit secrets. Keep only safe public frontend keys in .env.local.

4) Supabase Database Setup

  1. Open Supabase SQL Editor.
  2. Run schema file:
supabase/schema.sql
  1. Run tenant productization migration:
supabase/migrations/20260301_tenant_productization.sql
  1. If profile image upload fails with bucket errors, run:
supabase/avatar_bucket_fix.sql

5) Start the Store

npm run dev

Open: http://localhost:3000

6) Admin Initial Configuration

  1. Login with admin email.
  2. Go to Admin > Settings > General:
    • Site name, support info, logos, footer content, social links
    • Currency and exchange rates
  3. Go to Admin > Settings > Company & Legal Pages:
    • Add/Edit/Remove pages (About, Contact, Privacy, Terms, etc.)
  4. Go to Admin > Settings > Plans & Features (super admin):
    • Select plan: Basic / Pro / Enterprise
    • Set license key and status
    • Enable/disable feature flags

7) Payment Setup (Optional bKash)

Deploy Supabase edge functions:

supabase functions deploy bkash-create-payment
supabase functions deploy bkash-callback

Set required function secrets in Supabase:

  • BKASH_PROVIDER
  • BKASH_BASE_URL
  • BKASH_USERNAME
  • BKASH_PASSWORD
  • BKASH_APP_KEY
  • BKASH_APP_SECRET
  • BKASH_CALLBACK_URL
  • STORE_FRONTEND_URL

8) Final Validation Checklist

  1. Run productization checks: 
    npm run test:productization
  2. Run production build: 
    npm run build
  3. Check branding appears correctly in header/footer/admin.
  4. Verify products, checkout, payment methods, and support ticket flow.
  5. Verify disabled plan features are not accessible.

9) Docker Run (Optional)

docker compose up --build

Open: http://localhost:3000

10) Support Handover Notes

  • Default deployment model is single tenant per customer.
  • Each customer should use separate Supabase project/database.
  • For multi-tenant rollout later, use provided scaffold migration and resolver helper.
